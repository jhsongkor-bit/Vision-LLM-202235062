## 참고 사항

코드 작성은 AI를 사용하지 않고 기존 실습 파일의 내용을 복사한 후 일부 수정하는 방식으로 진행하였습니다.

마스크 생성 과정에서 오프닝과 클로징을 비교한 결과, 오프닝을 적용했을 때 더 깔끔하게 영역이 검출되어 오프닝을 선택하였습니다.

이후 오프닝의 반복 횟수를 1-3회로 변경하여 비교한 결과 2회를 적용했을 때 가장 깔끔한 결과를 얻을 수 있어 이를 선택하였습니다. 이후 클로징도 1-3회 추가로 적용해 보았으나, 기존 결과와 큰 차이가 없어 추가로 적용하지 않았습니다.

따라서 최종 마스크는 강화 마스크에 오프닝을 2회 적용한 결과로 선정하였습니다.

영역 색칠은 기존 실습 코드를 그대로 활용하였습니다.
