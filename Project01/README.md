## 창의성 및 확장성

### 아이디어 설명

카메라로 사용자의 손동작과 공의 위치를 실시간으로 인식하여 별도의 컨트롤러 없이 손가락 제스처만으로 가상 탄환을 발사하여 특정 객체를 맞추는 게임을 구현했습니다.

손가락 관절의 각도를 분석해 검지가 펴지고 나머지 손가락이 접힌 상태를 총 모양으로 판별합니다. 총 자세가 새롭게 감지되면 가상 탄환을 발사하며 공의 위치를 추적해 공의 예측 위치와 탄환과의 충돌 여부를 판단합니다.

이를 통해 실제 사용자의 손동작과 물리적 객체의 움직임을 가상 탄환 및 명중 효과와 연결하여, 카메라 기반의 상호작용형 게임을 구현했습니다.

<br>

### 구현한 내용

- 공 검출: cv2.cvtColor()로 LAB 색 공간으로 변환하고, cv2.inRange()로 초록색 공 영역을 분리합니다.

- 영상 전처리: cv2.GaussianBlur()로 가우시안 블러를 적용하고 cv2.morphologyEx()를 통해 오프닝 방식을 2번 적용하였습니다.

- 윤곽선 검출: cv2.findContours()로 공 후보 영역을 찾고, cv2.contourArea()로 면적을 계산해 가장 큰 영역을 선택합니다.

- 공 추적: cv2.KalmanFilter()의 predict()와 correct()로 공의 위치를 예측하고 실제 검출 위치를 반영합니다.

- 손 인식: MediaPipe Hand Landmarker를 사용해 손 랜드마크를 검출합니다.

- 제스처 인식: calculate_angle() 함수로 손가락 관절 각도를 계산합니다. 이때 검지는 160도 초과로 펴지면서 밑 세 손가락은 90도 미만으로 접혀지면 총 모양으로 감지합니다.

- 가상 탄환 구현: 프레임별 좌표 갱신을 통해 탄환을 이동시키고 cv2.circle()로 화면에 표시합니다.

- 충돌 판정: point_to_segment_distance()로 두 원의 중심점 사이의 거리가 두 원의 반지름 합의 미만인 경우 충돌로 판단합니다.

- 결과 오버레이: cv2.circle(), cv2.putText(), cv2.imshow()를 이용해 손 관절, 공, 탄환 및 인식 결과를 화면에 표시합니다.
